# Easy Study

Початок розробки освітньої платформи Easy Study. Інтерфейс першого етапу створено на Next.js, React та TypeScript; стилі — Tailwind CSS і власні адаптивні компоненти.

## Запуск локально

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Стан реалізації

- **Етап 1 — інтерфейс:** адаптивна бічна навігація, огляд учня, навчальна статистика, оцінки, розклад, інтерактивний список завдань і сторінки розділів.
- Дані на огляді навмисно позначені як прикладові й не надходять із бази даних.
- Авторизацію, профілі, Supabase/PostgreSQL, права доступу, реальні повідомлення та ES AI ще потрібно підключити.
